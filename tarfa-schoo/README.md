# مدرسة طرفا البحرية الثانوية المشتركة - نظام إدارة الفصول

## التقنيات
- الواجهة: Vite + React 19 + Tailwind CSS v4 + react-router
- الخادم: دوال Vercel Serverless في مجلد `api/`
- قاعدة البيانات والمصادقة والتخزين: Supabase

## التشغيل محلياً
1. `npm install`
2. انسخ `.env.example` إلى `.env` واملأ القيم.
3. `npm run dev` للتطوير، و`npm run build` للبناء.

## الإعداد الأول
- افتح `/setup` وأدخل رمز الإعداد لمرة واحدة لإنشاء حساب المدير الأول.
- بعدها يدير المدير كل الحسابات من التطبيق.

## الأمن
- كلمات السر تُحفظ مُجزّأة عبر Supabase Auth.
- الرقم القومي مشفّر (AES-256-GCM) على الخادم.
- كل الجداول محمية بسياسة RLS تمنع الوصول المباشر، والوصول يتم عبر الخادم فقط.
- الصلاحيات تُطبَّق في دوال الخادم، ومفتاح الخدمة لا يصل إلى المتصفح.
- ترويسات أمان HTTP مضبوطة في `vercel.json`.

## هيكل المشروع
- `api/` دوال الخادم (الطلاب، المعلمون، الغياب، الدرجات، السلوك، القناة، الشات...)
- `lib/` أدوات الخادم (الصلاحيات، التشفير)
- `src/pages/` صفحات الواجهة، `src/components/` المكونات، `src/contexts/` الحالة العامة
- `public/` الشعار وصورة المدرسة والأيقونة
